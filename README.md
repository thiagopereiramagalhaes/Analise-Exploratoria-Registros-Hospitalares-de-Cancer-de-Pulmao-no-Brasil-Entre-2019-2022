# Análise Exploratória de Registros Hospitalares de Câncer de Pulmão no Brasil (2019-2022)

## 1. O que é este projeto?

Este projeto é uma análise de dados focada em compreender o cenário do câncer de pulmão no Brasil, baseando-se em registros hospitalares coletados entre os anos de 2019 e 2022. A principal fonte de informação utilizada é o Instituto Nacional de Câncer (INCA), a maior referência do país no assunto.

Muitas vezes, os dados de saúde pública são massivos, complexos e difíceis de interpretar por quem não é da área. Este projeto resolve exatamente esse problema: ele transforma um grande volume de dados brutos e planilhas de hospitais em informações claras e fáceis de entender. 

Ao explorar esses registros, o projeto ajuda a criar um panorama visual sobre a doença no país, permitindo identificar tendências de diagnósticos, o perfil dos pacientes mais afetados e o impacto ao longo dos anos analisados. É uma ferramenta útil não apenas para profissionais da saúde e pesquisadores, mas também para a sociedade em geral, auxiliando na conscientização e no entendimento da evolução do câncer de pulmão no Brasil.

## 2. Como o fiz?

O projeto foi inteiramente desenvolvido através da linguagem de programação Python, utilizando um ambiente de documento interativo chamado *Jupyter Notebook*. O processo seguiu as principais etapas de uma Análise Exploratória de Dados (EDA):

* **Coleta de Dados:** Importamos a base de dados oficial do INCA, focando especificamente nos pacientes diagnosticados com câncer de pulmão no período de 2019 a 2022.
* **Limpeza e Tratamento:** Dados do mundo real costumam vir com falhas, valores em branco ou formatos confusos. O primeiro passo prático foi "limpar a casa", organizando e padronizando as informações para garantir que a análise fosse precisa e livre de erros.
* **Exploração de Padrões:** Com os dados organizados, começamos a fazer perguntas às informações: investigar volumes de casos, distribuições demográficas e possíveis impactos ao longo dos anos estipulados.
* **Visualização de Dados:** Para que as respostas fossem compreensíveis para pessoas não técnicas, traduzimos os números e estatísticas em resumos e gráficos visuais. Isso facilita a interpretação dos resultados com apenas um "bater de olhos".
